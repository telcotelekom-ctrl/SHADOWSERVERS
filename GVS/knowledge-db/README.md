# GVS Knowledge DB

Deze map is de centrale kennisdatabase voor GVS.

## Structuur
- schema.json: tabelmodel en velden
- records/db.json: actuele records
- logs/changelog.md: leesbare wijzigingshistorie

## Doel
- Geen losse documenten zonder context
- Alles vastleggen als verbonden records
- Herhaalbare updates met metadata, versies en relaties

## Kernprincipes
- Human-centered: netwerk dient de mens
- Traceerbaar: elke bron heeft een referentie-ID
- Groeiend: modules en kennis kunnen iteratief worden uitgebreid
- Reproduceerbaar: changelog en schema blijven synchroon
