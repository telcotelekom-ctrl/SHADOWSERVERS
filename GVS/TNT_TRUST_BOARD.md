# T.&.T. Trust Board

## Purpose
A fully playable browser-side mock board game for the GVS/TELADIA system.

## Rules
- 2 to 4 players.
- All value is symbolic and uses XSTOX mock coins only.
- No real money, no wallet transfer, no external payment execution.
- Players roll, move, claim regions, pay symbolic trust fees, and draw event cards.
- First player to keep the highest balance after the configured round limit wins.

## Theme
- T.&.T. Trust
- Architect System
- Network regions
- Mock coin economy
- Play Zone compatible

## Technical Scope
- Browser-only
- Local persistence with localStorage
- No backend required
- No copyrighted board branding used
