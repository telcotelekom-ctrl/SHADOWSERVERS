# Handbuch zur Nutzung

## Einstieg
- Öffne [index.html](index.html) für das Hauptportal – der serverlose ShadowOS-Kern bootet
  automatisch im Browser (kein Server erforderlich).
- Das Manifest liest du unter [shadowos-manifest.html](shadowos-manifest.html).

## Wichtige Schritte
1. Portal öffnen (lokal per Datei oder über GitHub Pages).
2. ShadowOS-Status im Portal prüfen (Shadow-Status-/Companion-Anzeige).
3. Optional: lokales Node-Backend starten, um Live-Features (Status/Companion/Profile) zu nutzen.
4. Ohne Backend arbeitet das Portal im Offline-/Shadow-Modus – das ist normal.

## Hinweis
Fehlermeldungen zu 127.0.0.1 oder /api in der Browser-Konsole betreffen nur das OPTIONALE
Backend und bedeuten nicht, dass ShadowOS offline ist.
